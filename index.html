多數爭議，都是因為「誰該做什麼」沒講清楚接下來兩頁：Account R&R／Project R&R
Account R&R：Account 該做的事
紅色標籤＝過去最常被抱怨的地方，對應到的就是這一項
客戶管理
  1. 1每月／每季跟客戶開會，保持固定溝通
  2. 2合約（TOS）談判與續約
  3. 3開發新案子，經營深度客戶關係
  4. 4處理客訴
  5. 5開發票、催收款項
  6. 6保證期替換：確認最後工作日、補人期間、折讓（CN）金額，並發 email 跟客戶確認 CN 金額與有效期限
專案管理
  1. 1開案並指派給 project 顧問與其直屬主管（系統會發 email 通知）
  2. 2主導 PPR/PPHM，提供公司資訊：賣點、客戶洞察、關鍵職位組織圖、薪酬福利結構PPR/PPHM 沒進來・客戶資訊掌握不到
  3. 3居中溝通，串起 project 和客戶找不到 Account、找不到 HR
  4. 4每兩週跟 project 和客戶追進度（KA 客戶：每週）
  5. 5協助 project 管理客戶期待，提供搜尋方向
  6. 6在客戶端協助 project 談薪被客戶砍價，毫無抵抗
  7. 7依合約重新計算 billing confirmation，交給客戶，在報到日前拿到 PO
Project R&R：Project 該做的事
紅色標籤＝過去最常被抱怨的地方，對應到的就是這一項
搜尋期間
  1. 1依 PPR/PPHM 的方向搜尋、推薦人選
  2. 2管理人選動機與期待（換工作原因、薪資期待、手上其他 offer）人選動機管理不清楚
  3. 3安排面試、幫人選準備，回收雙方 feedback
  4. 4定期更新進度給 account
成案時
  1. ✓上傳 LA、CANDID、薪資單（薪資核對 Excel）
  2. ✓LA 簽回後，提供 billing confirmation 給 accountBilling confirmation 沒弄
  3. ✓人選報到後持續追蹤，回報給 account／客戶
  4. ✓報到後跟客戶追蹤
Billing confirmation 交接流程（兩邊最常卡住的地方）

    GBL 評估：用不同視角看 Account
    GBL 任何時候都可以用不同視角，評估 Account 是否需要轉移；不論有無開案、有無關案

    關案 ≠ 守成做得好

    很多時候不是沒做，而是做沒到位、做不出成果，或成果其實不是來自 Account 經營。

    對手強勢客戶持續把案子開給競爭對手
    客戶理解不深不了解組織、HM 與用人需求
    開案／關案率不佳有在跑，但轉換不出結果
    客訴處理不當問題發生時處理不夠到位
    客戶溝通不周全資訊落差、期待沒有對齊
    其他經營面向任何影響客戶潛力的因素
    🌱
    有經營客戶，不等於有發揮客戶所有的潛力隨時可以跟 Leader／GBL 討論怎麼 Grow 這個客戶；如果沒有心 Grow，就讓其他有心的同事來 Grow。

        2026 v2 重點整理

        記住這五件事就夠了
        Open 判定

        合約失效，或合約有效但 6 個月內沒有客勤、開案、Billing → 自動 Open，不需 GBL 確認

        有效動作

        實體／線上 BM、討論合約更新 → 6 個月保護；只寫「打給 HR」「去拿案子」不算

        轉移

        拿到新案子或續約成功 → Account Holder 換人，自己請 Ping 更新 IES

        GBL 評估

        任何時候都可以從不同視角，評估 Account 是否需要轉移

        先談好

        Account 和 Project 怎麼分工、怎麼拆，談好就照談好的走；有爭議時，才回到 Ground Rules
